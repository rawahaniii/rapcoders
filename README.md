🍽️ Smart Mess Tracker

Smart Hostel Food Management System

1. About the Project

Smart Mess Tracker is a web-based application developed using Python and Streamlit. It is designed to make hostel mess management easier, smarter, and more efficient.

The application allows hostel students to submit their daily meal preferences, while mess administrators can monitor meal bookings and food wastage.

The main aim of this project is to reduce food wastage, improve food management, and help hostel management make better decisions.

2. Problem Statement

In many hostels, food is prepared without knowing the exact number of students who will eat.

This creates several problems:

- Excessive food preparation.
- Unnecessary food wastage.
- Difficulty in estimating daily food requirements.
- Poor management of meal bookings.
- Increased mess expenses.

Smart Mess Tracker provides a digital solution to these problems.

3. Objectives

- To digitize the daily meal booking process.
- To collect student meal preferences.
- To help administrators monitor meal bookings.
- To calculate food consumption and wastage.
- To reduce unnecessary food preparation.
- To improve mess management and save money.

4. Key Features

👨‍🎓 Student Panel

- Enter student name.
- Enter room number.
- Select Breakfast, Lunch, or Dinner.
- Choose whether to take or skip a meal.
- Submit daily meal preferences.

👨‍💼 Admin Dashboard

- View daily meal bookings.
- Monitor student meal preferences.
- View student names and room numbers.
- Check booking records.

🍱 Food Wastage Management

- Enter total food prepared in kilograms.
- Enter total food wasted in kilograms.
- Calculate food consumed.
- Calculate food wastage percentage.
- View food wastage records.

📊 Reports and Statistics

- Display total students.
- Display today's meal bookings.
- Display food wastage statistics.
- Help administrators understand food usage.

7. How the System Works

1. The student opens the Smart Mess Tracker website.
2. The student selects the Student Panel.
3. The student enters their name and room number.
4. The student selects a meal preference.
5. The student submits the booking.
6. The administrator opens the Admin Dashboard.
7. The administrator checks the meal booking records.
8. Food preparation and wastage details are entered.
9. The system calculates food consumption and wastage percentage.

8. Food Wastage Calculation

Formula:

Food Consumed = Food Prepared − Food Wasted

Wastage Percentage = (Food Wasted / Food Prepared) × 100

Example:

- Food Prepared = 50 kg
- Food Wasted = 5 kg
- Food Consumed = 45 kg
- Wastage Percentage = 10%

9. Installation and Setup

Step 1: Install Python

Download Python from:
https://www.python.org/downloads/

Step 2: Install Streamlit

Open the VS Code terminal and run:

pip install streamlit pandas plotly

Step 3: Open the Project

Open your project folder in Visual Studio Code.

Step 4: Run the Application

Execute this command in the terminal:

python -m streamlit run app.py

Step 5: Open the Website

Open Google Chrome and visit:

http://localhost:8501

Your Smart Mess Tracker application will appear.
